#  MyImpact — Personal Landing Page

**MyImpact** is a modern, clean, and responsive landing page built with **HTML** and **CSS**. It showcases my skills as a beginner frontend developer and represents my first custom personal website project — fully designed and coded from scratch.



##  What I Built

This project was inspired by popular landing pages, but I wanted to make mine **unique** with:

- A custom layout  
- Real content (no lorem ipsum!)  
- Smooth responsive behavior using only **Flexbox** (no media queries)  
- A custom color palette and hero illustration  



##  Features

-  Header with logo and navigation  
-  Beautiful hero section with headline, paragraph, and image  
-  Feature cards highlighting key skills  
-  Clear call-to-action (CTA) button  
-  Client testimonial section  
-  Fully responsive layout using Flexbox
